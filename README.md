Työkalu hakee, mikä muutossarja kustakin katetusta E-säännöstä (Taulukko 1:n osiot A ja H) oli kyseisenä päivänä EU-tyyppihyväksynnässä voimassa oleva viite käyttöönottopäivän ja ajoneuvoluokan perusteella.

Data perustuu UNECE:n GlobalAutoRegs-tietokantaan ja asetukseen (EU) 2019/2144 (liite I, konsolidoitu 07.07.2024) sekä asetukseen (EU) 2022/1398. EU-viitteen alkamispäivät ennen vuotta 2019 ovat parhaan saatavilla olevan tiedon mukaisia arvioita, eivät kaikilta osin tarkistettuja voimaantulopäätöksiä — tarkista tarvittaessa EUR-Lexistä.

Tämä työkalu ei ole virallinen tyyppihyväksyntäasiakirja eikä korvaa Traficomin tai valmistajan antamaa tietoa.
